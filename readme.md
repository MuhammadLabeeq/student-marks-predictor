# 🎓 Student Final Marks Predictor

An end-to-end Machine Learning web application built with Python, Scikit-Learn, and Streamlit that predicts final exam scores based on weekly study habits, attendance, prior academic performance, and sleep metrics.

---

## 📊 Model Performance & Accuracy

- **Overall Model Accuracy:** ~85.8% (based on MAPE)
- **Mean Absolute Error (MAE):** ~7.81 marks
- **Variance Explained ($R^2$ Score):** 50.6%
- **Predictions within $\pm10$ Marks:** 69.8% of test set

---

## 🛠️ Features & Tech Stack

* **Machine Learning:** Scikit-Learn (`RandomForestRegressor`)
* **Web UI:** Interactive Streamlit dashboard with real-time sliders
* **Data Processing & Visualization:** Pandas, NumPy, Matplotlib
